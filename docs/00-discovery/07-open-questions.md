## ステータスの凡例

| Status | 意味 |
| --- | --- |
| `open` | 未回答 |
| `proposed-by-claude` | Claude が暫定回答を提示済。**人間の承認待ち**。承認されたら `answered`、差し戻されたら回答列を更新して `open` または `answered` に再分類する。この値は本プロジェクト固有の非公式ステータスで、ハーネス全体ルールでの `answered` には**まだ昇格していない**ことを示す |
| `answered` | 回答済（回答列に内容を記載） |
| `deferred` | 後段（Phase 1 以降）で扱う |
| `dropped` | 不要と判断（理由を回答列に） |

> `proposed-by-claude` の運用ルール（B 方針）:
> - Claude は引用元（プロンプト本文 / 既存ドキュメント）が明示できる質問にのみ暫定回答を出す。
> - この暫定回答に依存して書いた `RC-XXX` は `### Status: needs-clarification` を初期値とし、人間が `proposed-by-claude` を承認した時点で `refined` への昇格候補にする。
> - 人間がこの欄の暫定回答を読んで違和感があれば、回答列に **追記**（差し戻しコメント）するか、ステータスを `open` に戻す。
> - 2026-05-03 時点で `proposed-by-claude` のもの: Q-001, Q-002, Q-003, Q-007, Q-009, Q-010, Q-011, Q-013（8 件）。
> - 2026-05-03 第 1 回 `/review-requirements all` を受けて新規追加: Q-016, Q-017, Q-018, Q-019（いずれも `open`）。

## 質問の書き方

- 1 質問 = 1 行。複合質問は分割する。
- 回答可能な相手を明記する（不在なら「未割当」と書く）。
- 「YES/NO」「数値」「列挙」など、期待する回答の形式が想像できる質問にする。
