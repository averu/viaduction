# API-012 — list myProposals（自分の投稿一覧 loader）

## 概要

ログインユーザが自分が起票した提案を全 8 ステータス横断で一覧する loader（REQ-007）。`author_id == viewer.user_id` で server-side フィルタする。guest は 401。

## エンドポイント

```
GET /v1/me/proposals
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: `user` 以上（`reviewer` / `admin` / `auditor` も自身の投稿があれば閲覧可）。guest は 401
- **リソース所有者一致**: `author_id == viewer.user_id` のみ返す（server-side フィルタ）
- **CSRF 検証**: GET のため不要
- **レート制限**: MVP 対象外（Q-013 暫定）
- **公開バイパス**: 対象外

## リクエスト

### パスパラメータ

なし。

### クエリパラメータ

| 名前 | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `cursor` | string | no | null | カーソル（`updated_at` ベースの不透明文字列） |
| `limit` | integer | no | 20 | 1〜100 |
| `status` | string | no | (全件) | フィルタ用 status（`draft` / `submitted` / ...）。指定時は当該 status のみ。Phase 3 では Open Question 扱いだが、本 API では実装可能オプションとして規定 |

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | yes | 認証 cookie |

## レスポンス

### 200 OK

```json
{
  "items": [
    {
      "proposal_id": "01HXYZ...",
      "title": "○○交差点の歩道整備に関する提案",
      "status": "returned",
      "visibility": "internal",
      "updated_at": 1746360000000,
      "submitted_at": 1746000000000,
      "published_at": null,
      "withdrawn_at": null,
      "version": 4
    }
  ],
  "next_cursor": null,
  "has_more": false
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `items[].proposal_id` | string (uuid v7) | yes | ID |
| `items[].title` | string | yes | タイトル |
| `items[].status` | string | yes | 全 8 値のいずれか |
| `items[].visibility` | string | yes | `private` / `internal` / `public` |
| `items[].updated_at` | integer | yes | 最終更新時刻 |
| `items[].submitted_at` | integer \| null | no | 直近の提出時刻 |
| `items[].published_at` | integer \| null | no | 公開時刻 |
| `items[].withdrawn_at` | integer \| null | no | 取り下げ時刻 |
| `items[].version` | integer | yes | 楽観ロック用 |
| `next_cursor` | string \| null | no | 次ページ用 |
| `has_more` | boolean | yes | 次ページの有無 |

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | `limit` / `cursor` / `status` 値の不正 |
| 401 | `UNAUTHENTICATED` | guest（cookie なし or 許可リスト外） |
| 500 | `INTERNAL_ERROR` | 想定外 |

> 404 は本 API では発生しない（自分の投稿が 0 件でも 200 + 空リスト）。

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | read | `WHERE author_id=viewer.user_id [AND status=?]` + `ORDER BY updated_at DESC` + `LIMIT limit`。`ix_proposals_author_id` を使用 |
| DB-006 (users) | read | `findById(viewer.user_id)` で role 確認 |

## 認可拒否時の挙動

| 拒否シナリオ | HTTP | logger `403_reason` |
| --- | --- | --- |
| cookie なし | 401 | `not_authenticated` |

副作用なし。

- `limit`: 1〜100
