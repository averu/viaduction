# API-003 — startReview（担当開始 server function）

## 概要

`reviewer` または `admin` が `submitted` 状態の提案を `in_review` に遷移させ、自身を assignee として登録する mutation。同時担当化は楽観ロックで 1 名のみ成功する（`BR-REVIEW-02`）。reason 必須（`BR-REVIEW-01`）。

## エンドポイント

```
POST /v1/proposals/{id}/start_review
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: `reviewer` または `admin`（OR 合成、`BR-AUTHZ-01`）。`user` / `auditor` は 404
- **リソース所有者一致**: 不要（reviewer は他人の投稿を担当する）。ただし `private` 投稿は除外（Q-016 暫定、reviewer から見えない → 404）
- **CSRF 検証**: Origin / Sec-Fetch-Site=same-origin（NFR-006）
- **レート制限**: MVP 対象外（Q-013 暫定）
- **公開バイパス**: 対象外（`authorize()` 必須）

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string (uuid v7) | yes | 対象 proposal の ID（`status='submitted'` 前提） |

### クエリパラメータ

なし。

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | yes | モック認証 cookie（許可リスト + role が `reviewer` または `admin`） |
| `Origin` | yes | 同一オリジン |
| `Sec-Fetch-Site` | yes | `same-origin` |

### ボディ

```json
{
  "reason": "広報担当として一次レビューを担当します",
  "expected_version": 1
}
```

#### スキーマ

| フィールド | 型 | 必須 | 制約 |
| --- | --- | --- | --- |
| `reason` | string | **yes** | 1〜4000 文字、空白のみは不可（trim 後 1 文字以上、`BR-REVIEW-01`）。PII を含めない運用（NFR-005、AMB-012） |
| `expected_version` | integer | yes | proposal の現 `version`。CAS で `WHERE version=expected_version`、失敗時 409（`BR-REVIEW-02`） |

## レスポンス

### 200 OK

```json
{
  "proposal_id": "01HXYZ...",
  "status": "in_review",
  "assignee_id": "01HXYZ-user-r1",
  "version": 2,
  "audit_log_id": "01HXYZ-al..."
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `proposal_id` | string (uuid v7) | yes | 対象 proposal ID |
| `status` | string | yes | 常に `"in_review"` |
| `assignee_id` | string (uuid v7) | yes | caller の `users.id`（DB-003 不変条件 4） |
| `version` | integer | yes | +1 された値 |
| `audit_log_id` | string (uuid v7) | yes | append された AuditLog エントリの ID |

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | reason 空 / 4000 文字超 / `expected_version` 欠落 |
| 401 | `UNAUTHENTICATED` | cookie なし |
| 404 | `NOT_FOUND` | proposal 存在しない / role 不足（`user` / `auditor`）/ `private` 投稿の reviewer アクセス |
| 409 | `CONFLICT` | 楽観ロック失敗（同時担当化、別 reviewer が先行） |
| 422 | `BUSINESS_RULE_VIOLATION` | `status != 'submitted'` |
| 500 | `INTERNAL_ERROR` | 想定外例外 |

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | write (UPDATE, CAS) | `WHERE id=? AND version=expected_version AND status='submitted'` で `status='in_review'`、`assignee_id=viewer.user_id`、`updated_at=now`、`version+1` |
| DB-004 (audit_logs) | append (INSERT) | 末尾で append（reason 必須） |
| DB-006 (users) | read | `findById(viewer.user_id)` で role 確認 |

## AuditLog 書き込み

| フィールド | 値 |
| --- | --- |
| `action` | `start_review` |
| `actor_id` | `viewer.user_id` |
| `actor_role` | `viewer.roles` スナップショット（例: `reviewer` または `reviewer,admin`） |
| `target_proposal_id` | パス引数 `id` |
| `before_status` | `submitted` |
| `after_status` | `in_review` |
| `reason` | リクエスト `reason`（NOT NULL） |
| `policy_agreement_id` | NULL |
| `created_at` | `now()` |

`reason` 必須要否: **必須**（`BR-REVIEW-01`）。空文字 / 空白のみは 400 で停止 → AuditLog 記録なし。

## 認可拒否時の挙動

| 拒否シナリオ | HTTP | logger `403_reason` |
| --- | --- | --- |
| cookie なし | 401 | `not_authenticated` |
| cookie あるが role が `user` のみ / `auditor` | 404 | `insufficient_role` |
| reviewer が `private` 投稿を呼んだ（Q-016 暫定） | 404 | `insufficient_role`（補助情報: `private_blocked`） |
| Origin 不一致 (CSRF, B-2) | **403** | `cross_site` |

副作用なし（`BR-AUDIT-03`）。

## バリデーション規約

- ライブラリ: Zod（暫定）
- 順序:
  1. ボディスキーマ（reason 必須 / 文字数）→ 400
  2. authorize（role: reviewer or admin）→ 404
  3. proposal 取得 → `status === 'submitted'` を確認 → 422
  4. visibility が `private` で role が reviewer のみ → 404（Q-016 暫定）
  5. CAS UPDATE → 失敗で 409

## エラーコード

| HTTP | コード | 用途 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | reason 空 / 文字数超過 |
| 401 | `UNAUTHENTICATED` | 未認証 |
| 404 | `NOT_FOUND` | role 不足 / `private` ブロック / 不存在 |
| 409 | `CONFLICT` | 楽観ロック失敗 |
| 422 | `BUSINESS_RULE_VIOLATION` | `status != 'submitted'` |
| 500 | `INTERNAL_ERROR` | 想定外 |
