# API-016 — list auditLogs（監査ログ一覧 loader）

## 概要

`auditor` または `admin` が AuditLog エントリ全件をフィルタ付きで一覧する loader（REQ-012 / UC-015）。フィルタ: `actor_id` / `action` / `target_proposal_id` / `created_at` 範囲。`user` / `reviewer` は 404、`guest` は 401。

## エンドポイント

```
GET /v1/audit/logs
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: `auditor` または `admin`
- **リソース所有者一致**: 不要
- **CSRF 検証**: GET のため不要
- **レート制限**: MVP 対象外（Q-013 暫定）
- **公開バイパス**: 対象外

## リクエスト

### パスパラメータ

なし。

### クエリパラメータ

| 名前 | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `cursor` | string | no | null | カーソル（`created_at` ベース） |
| `limit` | integer | no | 50 | 1〜200 |
| `actor_id` | string (uuid v7) | no | (全件) | actor フィルタ |
| `action` | string | no | (全件) | action フィルタ（DB-004 の 8 値、CSV で複数指定可: `action=submit,publish`） |
| `target_proposal_id` | string (uuid v7) | no | (全件) | 対象 proposal フィルタ |
| `from` | integer | no | (なし) | `created_at >= from`（Unix epoch millis） |
| `to` | integer | no | (なし) | `created_at < to`（Unix epoch millis） |

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | yes | 認証 cookie（auditor / admin） |

## レスポンス

### 200 OK

```json
{
  "items": [
    {
      "audit_log_id": "01HXYZ-al-1",
      "actor_id": "01HXYZ-user-r1",
      "actor_role": "reviewer",
      "action": "approve",
      "target_proposal_id": "01HXYZ-p1",
      "before_status": "in_review",
      "after_status": "approved",
      "before_visibility": null,
      "after_visibility": null,
      "reason_present": true,
      "policy_agreement_id": null,
      "created_at": 1746360000000
    }
  ],
  "next_cursor": null,
  "has_more": false
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `items[].audit_log_id` | string (uuid v7) | yes | エントリ ID |
| `items[].actor_id` | string (uuid v7) | yes | 操作実行者 |
| `items[].actor_role` | string | yes | スナップショット role |
| `items[].action` | string | yes | DB-004 の `action` 値 |
| `items[].target_proposal_id` | string (uuid v7) | yes | 対象 proposal |
| `items[].before_status` / `after_status` | string \| null | no | 遷移前後（visibility 操作では NULL） |
| `items[].before_visibility` / `after_visibility` | string \| null | no | MVP では常に NULL |
| `items[].reason_present` | boolean | yes | reason の有無のみ返す（**reason 本体は一覧では返さない**、NFR-005 PII 除外と整合。本体は API-017 詳細で取得） |
| `items[].policy_agreement_id` | string \| null | no | submit / resubmit 時のみ |
| `items[].created_at` | integer | yes | 記録時刻 |
| `next_cursor` | string \| null | no | 次ページ用 |
| `has_more` | boolean | yes | 次ページの有無 |

> 並び順: `created_at DESC`（最新が先頭、REQ-012）。

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | クエリ不正（`limit` / `from > to` / `action` の値不正） |
| 401 | `UNAUTHENTICATED` | guest |
| 404 | `NOT_FOUND` | role が `auditor` / `admin` 以外 |
| 500 | `INTERNAL_ERROR` | 想定外 |

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-004 (audit_logs) | read | フィルタに応じて `ix_audit_logs_actor` / `ix_audit_logs_action` / `ix_audit_logs_target_proposal` / `ix_audit_logs_created_at` のいずれかを使用。複数フィルタ同時の最適化は Phase 5 で実装 |
| DB-006 (users) | read | viewer の role 確認 |

> AuditLog repository の `list(filter, cursor, limit)` を呼ぶ。`update` / `delete` は呼ばない（NFR-004）。

## 認可拒否時の挙動

| 拒否シナリオ | HTTP | logger `403_reason` |
| --- | --- | --- |
| cookie なし | 401 | `not_authenticated` |
| role が `user` のみ / `reviewer`（auditor / admin を含まない） | 404 | `insufficient_role` |

副作用なし。

## バリデーション規約

- Zod（暫定）
- `action`: enum (DB-004 CHECK と一致、CSV パース可)
- `from` / `to`: integer。`from > to` なら 400
- `limit`: 1〜200

| HTTP | コード | 用途 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | クエリ不正 |
| 401 | `UNAUTHENTICATED` | guest |
| 404 | `NOT_FOUND` | role 不足 |
| 500 | `INTERNAL_ERROR` | 想定外 |
