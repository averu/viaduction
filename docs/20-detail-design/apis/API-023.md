# API-023 — updateDraft（draft 本文編集 server function）

## 概要

投稿者本人が draft 状態の proposal を部分編集する mutation（B-4 採番、楽観ロック対応）。
**AuditLog 書き込みは行わない**（BR-PROPOSAL-01 の「結果を変える 5 種・8 操作」に含めない、UC-014 対象外）。
本 API は SCR-004（投稿フォーム）/ SCR-006（自分の投稿詳細）の「編集」導線で使われる。

## エンドポイント

```
PATCH /v1/proposals/{id}
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: 投稿者本人のみ（`author_id == viewer.user_id`）かつ `proposal.status == 'draft'`
- **リソース所有者一致**: `author_id != viewer.user_id` または `status != 'draft'` → **404**（リソース存在隠蔽、暫定統一）
- **CSRF 検証**: Origin / Sec-Fetch-Site=same-origin（NFR-006）。違反時は **403 CSRF_DENIED** + logger `403_reason=cross_site`
- **レート制限**: MVP 対象外（Q-013 暫定）

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | string (UUID v7) | yes | proposal id |

### ボディ

```json
{
  "title": "（オプション）",
  "body": "（オプション）",
  "visibility": "private",
  "expected_version": 2
}
```

#### スキーマ

| フィールド | 型 | 必須 | 制約 |
| --- | --- | --- | --- |
| title | string | no | 指定時のみ更新。1〜200 文字、空白のみは無効 |
| body | string | no | 指定時のみ更新。1〜10000 文字、空白のみは無効 |
| visibility | enum | no | 指定時のみ更新 |
| expected_version | integer | yes | 楽観ロック。現在の `proposals.version` と一致しない場合 409 |

## レスポンス

### 200 OK

```json
{
  "proposal_id": "01J...",
  "status": "draft",
  "version": 3,
  "updated_at": 1714960000000
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| proposal_id | string (UUID v7) | yes | リクエストの id と同一 |
| status | "draft" | yes | 編集後も draft |
| version | integer | yes | 楽観ロック更新後の値（`expected_version + 1`）|
| updated_at | integer (epoch ms) | yes | 更新時刻 |

### 4xx / 5xx

| ステータス | アプリコード | 状況 | logger `403_reason` |
| --- | --- | --- | --- |
| 400 | VALIDATION_ERROR | フィールド長 / 形式違反 | (出力なし) |
| 401 | UNAUTHENTICATED | 未ログイン (guest) | `not_authenticated` |
| 403 | CSRF_DENIED | Origin / Sec-Fetch-Site 不一致 | `cross_site` |
| 404 | NOT_FOUND | proposal 存在しない、または `author_id != viewer` または `status != 'draft'` | `not_owner` または `status_not_draft` |
| 409 | CONFLICT | 楽観ロック失敗（`expected_version != proposals.version`）| (出力なし) |
| 500 | INTERNAL_ERROR | サーバ内部エラー | (出力なし) |

## 認可拒否時の挙動

- **HTTP**: 暫定統一に従い「未ログイン 401 / 認可違反 404 / CSRF 違反 403」（B-2）
- **logger**: NFR-007 二段構造。`403_reason` で `not_owner` / `status_not_draft` 等の事由コードを残す

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | read → write (UPDATE) | 1) `id` で取得 → version 検証 → 2) UPDATE で `version+1`、`updated_at=Date.now()`、提供されたフィールドのみ更新 |

**AuditLog 書き込みなし**（draft 編集は「結果を変える操作」に含めない）。

## バリデーション規約

- 入力検証ライブラリ: Zod 暫定（Phase 5 で確定）
- 部分更新: `z.object({ title: z.string().optional(), ..., expected_version: z.number().int().nonnegative() })`
- 全フィールド未指定でも `expected_version` のみで no-op UPDATE は許容（`updated_at` のみ更新、version は +1）
