# API-009 — resubmit（再提出 server function、投稿者本人のみ）

## 概要

投稿者本人が `returned` の自身の提案を再編集（`title` / `body`）したうえで `submitted` に戻す mutation。同一 `proposal_id` を維持（`BR-RESUBMIT-01`）。倫理ガード再確認 / PolicyAgreement 再生成は **行わない**（Q-018 暫定、初回同意の継続適用）。reason は任意（Q-019 暫定）。

## エンドポイント

```
POST /v1/proposals/{id}/resubmit
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: `user` 以上（投稿者本人）。reviewer / admin / auditor が他人の returned proposal を再提出することは不可（404）
- **リソース所有者一致**: `proposals.author_id == viewer.user_id` を `assertOwner` で検証
- **CSRF 検証**: Origin / Sec-Fetch-Site=same-origin（NFR-006）
- **レート制限**: MVP 対象外（Q-013 暫定）

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string (uuid v7) | yes | `status='returned'` 前提、author 一致 |

### ボディ

```json
{
  "title": "○○交差点の歩道整備に関する提案（再提出）",
  "body": "差し戻しコメントを反映し、固有名詞を一般化しました…",
  "reason": null,
  "expected_version": 4
}
```

#### スキーマ

| フィールド | 型 | 必須 | 制約 |
| --- | --- | --- | --- |
| `title` | string | yes | 1〜200 文字、trim 後 1 文字以上（DB-003 と整合）。空文字は不可（`BR-PROPOSAL-02` 相当） |
| `body` | string | yes | 1〜10,000 文字、trim 後 1 文字以上 |
| `reason` | string \| null | no | 任意（Q-019 暫定）。指定する場合 1〜4000 文字 |
| `expected_version` | integer | yes | CAS 用 |

> **visibility 変更不可**: 本 API では `visibility` を受け取らない。visibility 変更は MVP 対象外（RC-005 needs-clarification、DB-003 不変条件 7）。

> **倫理ガード / PolicyAgreement**: 再提示しない（Q-018 暫定、REQ-013 AC 4）。リクエストに `ethics_check_*` / `policy_agreement_consent` を含めない。

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | yes | 認証 cookie |
| `Origin` | yes | 同一オリジン |
| `Sec-Fetch-Site` | yes | `same-origin` |

## レスポンス

### 200 OK

```json
{
  "proposal_id": "01HXYZ...",
  "status": "submitted",
  "submitted_at": 1746360000000,
  "version": 5,
  "audit_log_id": "01HXYZ-al..."
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `proposal_id` | string | yes | 対象 ID（不変、`BR-RESUBMIT-01`） |
| `status` | string | yes | `"submitted"` |
| `submitted_at` | integer | yes | 上書き更新後の値（DB-003） |
| `version` | integer | yes | +1 |
| `audit_log_id` | string | yes | append された AuditLog ID |

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | title / body 空 / 文字数超過 |
| 401 | `UNAUTHENTICATED` | cookie なし |
| 404 | `NOT_FOUND` | author 不一致（reviewer / admin / 他 user / auditor）/ proposal 不存在 |
| 409 | `CONFLICT` | 楽観ロック失敗 |
| 422 | `BUSINESS_RULE_VIOLATION` | `status != 'returned'` |
| 500 | `INTERNAL_ERROR` | 想定外 |

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | write (UPDATE, CAS) | `WHERE id=? AND version=expected_version AND status='returned' AND author_id=viewer.user_id` で `status='submitted'`、`title`、`body`、`submitted_at=now`（上書き）、`updated_at=now`、`version+1`。`current_policy_agreement_id` は据え置き（Q-018 暫定） |
| DB-004 (audit_logs) | append (INSERT) | `policy_agreement_id` には既存の `proposals.current_policy_agreement_id` をコピー |
| DB-006 (users) | read | author 一致確認 |

## AuditLog 書き込み

| フィールド | 値 |
| --- | --- |
| `action` | `resubmit` |
| `actor_id` | `viewer.user_id` |
| `actor_role` | スナップショット（`user`） |
| `target_proposal_id` | パス引数（不変） |
| `before_status` | `returned` |
| `after_status` | `submitted` |
| `reason` | リクエスト reason または NULL |
| `policy_agreement_id` | 既存の `proposals.current_policy_agreement_id` をコピー（NOT NULL、DB-004 不変条件 6） |
| `created_at` | `now()` |

`reason` 必須要否: **任意**（Q-019 暫定）。

## 認可拒否時の挙動

| 拒否シナリオ | HTTP | logger `403_reason` |
| --- | --- | --- |
| cookie なし | 401 | `not_authenticated` |
| `author_id != viewer.user_id`（他人の returned proposal を再提出） | 404 | `not_owner_resource` |
| reviewer / admin / auditor が呼ぶ（author でない） | 404 | `not_owner_resource` |
| Origin 不一致 (CSRF, B-2) | **403** | `cross_site` |

副作用なし。

## バリデーション規約

- Zod（暫定）
- 順序:
  1. ボディスキーマ（title / body 必須）→ 400
  2. authorize（owner 一致）→ 404
  3. proposal 取得 → `status='returned'` → 422
  4. CAS UPDATE → 409

| HTTP | コード | 用途 |
| --- | --- | --- |

| 401 | `UNAUTHENTICATED` | 未認証 |
| 404 | `NOT_FOUND` | author 不一致 / 不存在 |
| 409 | `CONFLICT` | 楽観ロック |
| 422 | `BUSINESS_RULE_VIOLATION` | `status != 'returned'` |
| 500 | `INTERNAL_ERROR` | 想定外 |
