# API-021 — get proposalForAdmin（admin 用 proposal viewer loader）

## 概要

admin が任意の proposal を全 visibility・全 status 横断で取得する loader（B-1 採番、SCR-013 公開操作画面が UC-007 publish / UC-008 withdraw の前確認に使う）。
API-013 (`get myProposal`) は「投稿者本人のみ」を要求するため、admin が他人の proposal を取得する経路として独立に採番した。

## エンドポイント

```
GET /v1/admin/proposals/{id}
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: **admin 専権**。`reviewer` / `user` / `auditor` は **404**、未ログイン (`guest`) は **401**
- **リソース所有者一致**: 不要（admin は全 proposal にアクセス可、author_id 制約なし）
- **CSRF 検証**: GET のため不要（NFR-006）
- **レート制限**: MVP 対象外（Q-013 暫定）

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | string (UUID v7) | yes | proposal id |

### クエリパラメータ

なし。

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| Cookie | yes | モック認証 cookie（`session_id`、NFR-006）|

### ボディ

なし（GET）。

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | string (UUID v7) | yes | proposal id |
| author_id | string | yes | 投稿者 user_id |
| title | string | yes | 最大 200 文字 |
| body | string | yes | 最大 10000 文字 |
| visibility | enum (private/internal/public) | yes | admin は全 visibility を返却 |
| status | enum | yes | 8 状態すべて返却（withdrawn も含む、admin は経緯確認のため可） |
| assignee_id | string \| null | yes | レビュアー担当者（補助情報、判定の権限制約には未使用、B-3 と整合）|
| current_policy_agreement_id | string \| null | yes | submitted 以降は NOT NULL（DB-005 不変条件）|
| version | integer | yes | 楽観ロック用 |
| created_at, updated_at | integer (epoch ms) | yes | |
| submitted_at, approved_at, published_at, withdrawn_at | integer \| null | yes | 各遷移時刻（DB-003 のカラム）|
| audit_log_history | array | yes | 直近 N=10 件の AuditLog（id / action / actor_id / created_at / reason_present のみ、reason 本体は API-017 経由で取得）|

### 4xx / 5xx

| ステータス | アプリコード | 状況 | logger `403_reason` |
| --- | --- | --- | --- |
| 401 | UNAUTHENTICATED | 未ログイン (guest) | `not_authenticated` |
| 404 | NOT_FOUND | proposal id が存在しない、または **admin 以外のロール**（権限不足はリソース存在隠蔽のため 404） | `insufficient_role`（admin 以外）|
| 500 | INTERNAL_ERROR | サーバ内部エラー | (出力なし) |

## 認可拒否時の挙動

- **HTTP**: 暫定統一に従い「未ログイン 401 / 認可違反 404」。**admin 以外のロールは権限不足を 404 で隠蔽**（NFR-007 と整合）。
- **logger**: `403_reason` フィールドに事由コードを記録する（HTTP 404 / 401 でも logger は内部観測用に事由を残す、NFR-007 二段構造）。

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | read | id でルックアップ、全 visibility・全 status |
| DB-004 (audit_logs) | read | `target_proposal_id={id}` で過去 N 件 |

AuditLog 書き込みは行わない（read-only loader、BR-AUDIT-01 の「結果を変える操作」に該当しない）。

## バリデーション規約

- 入力検証ライブラリ: Zod 暫定（Phase 5 で確定、NFR-002 / Workers 互換）
- パスパラメータ `id`: `z.string().uuid()` 等の制約
