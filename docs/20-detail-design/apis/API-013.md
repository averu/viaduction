# API-013 — get myProposal（自分の投稿詳細 loader）

## 概要

投稿者本人が自身の提案 1 件を全 8 ステータス横断で取得する loader（REQ-007 / UC-009 / UC-010）。`status='returned'` の場合は直近の `action='return'` の reason を併せて返す（再提出 SCR-006 で表示）。`status='withdrawn'` の自身投稿は 404（REQ-005 AC との整合）。

## エンドポイント

```
GET /v1/me/proposals/{id}
```

## 認可

- **レベル**: `authenticated`
- **必要ロール**: `user` 以上、ただし `author_id == viewer.user_id` 必須
- **リソース所有者一致**: `proposals.author_id == viewer.user_id`、違反時 404
- **CSRF 検証**: GET のため不要
- **レート制限**: MVP 対象外（Q-013 暫定）
- **公開バイパス**: 対象外

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string (uuid v7) | yes | 対象 proposal の ID |

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | yes | 認証 cookie |

## レスポンス

### 200 OK

```json
{
  "proposal_id": "01HXYZ...",
  "title": "○○交差点の歩道整備に関する提案",
  "body": "本文…",
  "visibility": "internal",
  "status": "returned",
  "author_id": "01HXYZ-user-a1",
  "created_at": 1745000000000,
  "updated_at": 1746360000000,
  "submitted_at": 1746000000000,
  "published_at": null,
  "withdrawn_at": null,
  "version": 4,
  "current_policy_agreement_id": "01HXYZ-pa...",
  "last_return_reason": {
    "reason": "本文に個人名が含まれている可能性があるため、該当箇所の修正をお願いします",
    "returned_at": 1746360000000,
    "audit_log_id": "01HXYZ-al-return"
  }
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `proposal_id` | string (uuid v7) | yes | ID |
| `title` | string | yes | タイトル |
| `body` | string | yes | 本文 |
| `visibility` | string | yes | `private` / `internal` / `public` |
| `status` | string | yes | 全 8 値のいずれか（ただし `withdrawn` は 404 で返さない） |
| `author_id` | string (uuid v7) | yes | viewer 自身と一致 |
| `created_at` | integer | yes | 作成時刻 |
| `updated_at` | integer | yes | 最終更新時刻 |
| `submitted_at` | integer \| null | no | 直近の提出時刻 |
| `published_at` | integer \| null | no | 公開時刻（`published`/`withdrawn` のみ NOT NULL、ただし withdrawn は 404 で到達しない） |
| `withdrawn_at` | integer \| null | no | （本 API からは常に NULL：withdrawn は 404 で隠蔽） |
| `version` | integer | yes | 楽観ロック用 |
| `current_policy_agreement_id` | string \| null | no | `submitted` 以降は NOT NULL |
| `last_return_reason` | object \| null | no | `status='returned'` のときのみ NOT NULL |
| `last_return_reason.reason` | string | yes (when present) | 直近の `action='return'` の reason |
| `last_return_reason.returned_at` | integer | yes (when present) | 当該 AuditLog エントリの `created_at` |
| `last_return_reason.audit_log_id` | string (uuid v7) | yes (when present) | AuditLog エントリ ID |

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | id 形式不正 |
| 401 | `UNAUTHENTICATED` | guest（cookie なし） |
| 404 | `NOT_FOUND` | proposal 不存在 / `author_id != viewer.user_id`（暫定統一）/ `status='withdrawn'`（自身投稿でも 404、REQ-005 AC） |
| 500 | `INTERNAL_ERROR` | 想定外 |

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | read | 主キー検索 + `author_id == viewer.user_id` 検証 + `status != 'withdrawn'` フィルタ |
| DB-004 (audit_logs) | read | `status='returned'` のみ追加クエリ: `WHERE target_proposal_id=? AND action='return' ORDER BY created_at DESC LIMIT 1`。`ix_audit_logs_target_proposal` を使用 |
| DB-006 (users) | read | viewer の role 確認 |

## 認可拒否時の挙動

| 拒否シナリオ | HTTP | logger `403_reason` |
| --- | --- | --- |
| cookie なし | 401 | `not_authenticated` |
| `author_id != viewer.user_id`（reviewer / admin / auditor / 他 user） | 404 | `not_owner_resource` |
| `status='withdrawn'` の自身投稿 | 404 | `withdrawn_filtered` |

副作用なし。
