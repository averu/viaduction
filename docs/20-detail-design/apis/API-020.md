# API-020 — logout（ログアウト server function）

## 概要

認証 cookie を破棄するログアウト（REQ-015 / UC-018）。DB アクセスなし。**idempotent**: 未認証で呼ばれても 200 を返す（cookie 状態を「無し」に揃えるだけ）。

## エンドポイント

```
POST /v1/auth/logout
```

## 認可

- **レベル**: `mixed`（cookie があれば破棄、なくても 200）
- **必要ロール**: なし
- **公開バイパス**: 部分的（cookie 持参者は authorize を通すが、結果に関わらず 200。認可違反では 401/404 を返さない）
- **CSRF 検証**: Origin / Sec-Fetch-Site=same-origin（NFR-006）。違反は 403 で拒否
- **レート制限**: MVP 対象外（Q-013 暫定）

## リクエスト

### パスパラメータ

なし。

### クエリパラメータ

なし。

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | no | あれば破棄、無くても OK |
| `Origin` | yes | 同一オリジン（NFR-006） |
| `Sec-Fetch-Site` | yes | `same-origin` |

### ボディ

なし（空ボディを許可）。

## レスポンス

### 200 OK

```json
{
  "logged_out": true
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `logged_out` | boolean | yes | 常に `true`（idempotent） |

#### Set-Cookie ヘッダ

```
Set-Cookie: session=; Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age=0
```

- `Max-Age=0`: cookie の即時失効
- 属性は API-019 と同じ（NFR-006）

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 403 | `CSRF_DENIED` | Origin 不一致 / Sec-Fetch-Site != same-origin |
| 500 | `INTERNAL_ERROR` | 想定外 |

> 401 / 404 は本 API では発生しない（idempotent）。

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| (DB アクセスなし) | — | cookie 破棄のみ |

## ログ出力

- 成功時: `user_id_hash`（cookie があった場合のみ）/ `logged_out=true` を logger に記録
- CSRF 拒否時: `403_reason=cross_site` を logger に記録

## バリデーション規約

- ボディは空、または `{}` を許可
- 余分なフィールドは無視

## エラーコード

| HTTP | コード | 用途 |
| --- | --- | --- |
| 403 | `CSRF_DENIED` | CSRF 検証失敗 |
| 500 | `INTERNAL_ERROR` | 想定外 |

## idempotency の保証

- 未認証で呼ばれても 200（`logged_out: true`）
- 同一セッションで複数回呼ばれても 200（`Set-Cookie` で再度失効指示）
- AuditLog 記録なし（mutation 系の AuditLog 対象は結果を変える 5 種・8 操作のみ、`BR-PROPOSAL-01` / `BR-AUDIT-01`）
