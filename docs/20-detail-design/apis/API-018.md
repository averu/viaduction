# API-018 — get policyDocument（ポリシー文書取得 loader、公開バイパス）

## 概要

投稿ポリシー（`posting`）またはプライバシーポリシー（`privacy`）の文書をログイン不要で取得する loader（REQ-014 / UC-017）。**公開バイパス対象**（認可ヘルパースキップ）。MVP では文書本体はリポジトリ内 markdown ファイルから読み込む想定（最終ディレクトリは Phase 5 で確定）。

## エンドポイント

```
GET /v1/policies/{kind}
```

## 認可

- **レベル**: `public`
- **必要ロール**: なし（全ロール 200）
- **公開バイパス**: **対象**（authorize ヘルパーをスキップ）。理由: REQ-014「ポリシー文書はログイン不要で閲覧可能」、`docs/10-basic-design/04-api-list.md` の公開バイパス一覧
- **CSRF 検証**: GET のため不要
- **レート制限**: MVP 対象外（Q-013 暫定）

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `kind` | string | yes | enum: `posting` / `privacy`。それ以外は 404 |

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | no | 任意（あっても無視、認可なし） |

## レスポンス

### 200 OK

```json
{
  "kind": "privacy",
  "policy_version": "mvp-initial",
  "title": "プライバシーポリシー",
  "content_markdown": "# プライバシーポリシー\n\n本サービスは…",
  "last_modified_at": 1745000000000
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `kind` | string | yes | `posting` または `privacy` |
| `policy_version` | string | yes | バージョン識別子。MVP では `mvp-initial`（DB-005 / API-002 と整合）。Q-008 確定後にバージョン番号体系を導入 |
| `title` | string | yes | 文書タイトル（表示用） |
| `content_markdown` | string | yes | Markdown 本文。XSS 対策として表示側で sanitize（NFR-006: `dangerouslySetInnerHTML` 禁止、表示は markdown レンダラ経由） |
| `last_modified_at` | integer | yes | 文書の最終更新時刻（Unix epoch millis、リポジトリ内ファイルの mtime もしくはハードコード） |

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 404 | `NOT_FOUND` | `kind` が `posting` / `privacy` のいずれでもない |
| 500 | `INTERNAL_ERROR` | 文書ファイル読み込み失敗等 |

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| (DB アクセスなし) | — | 文書はリポジトリ内 markdown を想定。Phase 5 で `docs/02-requirements/policies/posting.md` 等のディレクトリと読み込み実装を確定 |

> DB-005 (policy_agreements) は read しない（同意レコード側が真の値、文書側は静的）。

## 認可拒否時の挙動

公開バイパス対象のため認可拒否は発生しない。`kind` が enum 外の場合のみ 404（リソース不存在）。

## バリデーション規約

- Zod（暫定）
- `kind`: enum (`posting` / `privacy`)

## エラーコード

| HTTP | コード | 用途 |
| --- | --- | --- |
| 404 | `NOT_FOUND` | `kind` 不正 |
| 500 | `INTERNAL_ERROR` | 文書読み込み失敗 |

## キャッシュ

- レスポンスヘッダに `Cache-Control: public, max-age=3600` を付与可能（Phase 5 で確定、MVP では設定しなくてもよい）。
