# API-011 — get publishedProposal（公開投稿詳細 loader）

## 概要

`status='published'` の提案 1 件を viewer × visibility のマトリクス（REQ-008）に従って返す詳細 loader。`withdrawn` および非該当 visibility は 404 で隠蔽（暫定統一）。本文 `body` を含む。

## エンドポイント

```
GET /v1/proposals/{id}
```

## 認可

- **レベル**: `mixed`（guest 経路は `visibility='public'` のみ通過）
- **必要ロール**: visibility に依存
- **リソース所有者一致**: `private` の場合は `author_id == viewer.user_id` または admin
- **CSRF 検証**: GET のため不要
- **レート制限**: MVP 対象外（Q-013 暫定）
- **公開バイパス**: 部分的（guest かつ `visibility='public'` のときのみ。それ以外は authorize 必須）

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string (uuid v7) | yes | 対象 proposal の ID |

### ヘッダ

| 名前 | 必須 | 説明 |
| --- | --- | --- |
| `Cookie` | no | あれば authorize、無ければ guest 扱い |

## レスポンス

### 200 OK

```json
{
  "proposal_id": "01HXYZ...",
  "title": "○○交差点の歩道整備に関する提案",
  "body": "本文…",
  "visibility": "public",
  "author_id": "01HXYZ-user-a1",
  "status": "published",
  "published_at": 1746000000000,
  "updated_at": 1746360000000,
  "version": 4
}
```

#### スキーマ

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `proposal_id` | string (uuid v7) | yes | ID |
| `title` | string | yes | タイトル |
| `body` | string | yes | 本文 |
| `visibility` | string | yes | `public` / `internal` / `private` |
| `author_id` | string (uuid v7) | yes | 投稿者 ID |
| `status` | string | yes | `"published"` のみ（`withdrawn` は 404） |
| `published_at` | integer | yes | 公開時刻 |
| `updated_at` | integer | yes | 最終更新時刻 |
| `version` | integer | yes | 楽観ロック用バージョン |

### 4xx / 5xx

| ステータス | アプリコード | 状況 |
| --- | --- | --- |
| 401 | `UNAUTHENTICATED` | `visibility='internal'` または `private` を guest が要求（`403_reason=not_authenticated`） |
| 404 | `NOT_FOUND` | proposal 不存在 / `status='withdrawn'`（REQ-005 AC、loader フィルタで隠蔽）/ user(他人) が `private` 要求 / reviewer / auditor が `private` 要求（Q-016 暫定） |
| 500 | `INTERNAL_ERROR` | 想定外 |

## 副作用 / DB アクセス

| DB | 操作 | 備考 |
| --- | --- | --- |
| DB-003 (proposals) | read | 主キー検索（`pk_proposals`）。取得後にアプリ層で visibility × viewer のマトリクス検証 |
| DB-006 (users) | read | viewer が cookie 持参時のみ `findById` |

## visibility × viewer のマトリクス（REQ-008 と同期）

| visibility \ viewer | guest | user(他人) | user(本人) | reviewer | admin | auditor |
| --- | --- | --- | --- | --- | --- | --- |
| `private`   | 401 | 404 | 200 | 404（Q-016 暫定） | 200 | 404（Q-016 暫定） |
| `internal`  | 401 | 200 | 200 | 200 | 200 | 200 |
| `public`    | 200 | 200 | 200 | 200 | 200 | 200 |

- `status='withdrawn'` は viewer に関わらず 404（REQ-005 AC）。
- `status` が `published` 以外（draft / submitted / in_review / approved / returned / rejected）も 404（本 API は published のみ対象。draft は SCR-004 / 自身の投稿は API-013、レビュー中は API-015 を経由）。

## 認可拒否時の挙動

| 拒否シナリオ | HTTP | logger `403_reason` |
| --- | --- | --- |
| guest が `internal` または `private` を要求 | 401 | `not_authenticated` |
| user(他人) が `private` を要求 | 404 | `not_owner_resource` |
| reviewer が `private` を要求（Q-016 暫定） | 404 | `insufficient_role` |
| auditor が `private` を要求 | 404 | `insufficient_role` |
| 全 viewer が `withdrawn` を要求 | 404 | `withdrawn_filtered` |

副作用なし。

## バリデーション規約

- Zod（暫定）
- `id`: UUID v7 形式、不正なら 400（実装上は 404 として隠蔽してもよいが、明示的な形式不正は 400 を推奨）

## エラーコード

| HTTP | コード | 用途 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | id 形式不正 |
| 401 | `UNAUTHENTICATED` | guest が internal / private を要求 |
| 404 | `NOT_FOUND` | 不存在 / withdrawn / 認可違反（暫定統一） |
| 500 | `INTERNAL_ERROR` | 想定外 |
