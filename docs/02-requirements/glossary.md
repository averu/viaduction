# 用語集

このプロジェクトで使う用語の **唯一の定義先**。設計ドキュメント・コード・テストはこの定義に従う。
新しい概念を導入したら、まずここに追加してから本文で使う。

## 表記規約

- 用語は和名を主、英名を括弧で。例: `ユーザ (user)`。
- 略語は大文字。例: `SLA` (Service Level Agreement)。
- 同義語が複数あれば代表名を 1 つ決め、他は注記する。

| カテゴリ | フィールド例 |
